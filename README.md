# Follow the Star Maze ⭐

A simple, free maze game for children ages 5–10. Help the Wise Man follow the star through the maze and find Baby Jesus at the end.

## How to play
- Press **Start the journey**.
- Guide the Wise Man by dragging a finger on the maze, tapping the arrow buttons, or using the keyboard arrow keys.
- The timer starts on your first move. Reach the manger quickly to earn up to 3 stars.
- Every game creates a new maze, so it never repeats.

## Features
- Timer and star rating
- A 13×13 maze that is challenging but fair
- Touch, button and keyboard controls
- Works on phones, tablets and computers
- No account, no install, no ads
- Each child plays on their own device
